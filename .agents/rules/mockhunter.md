# MOCKHUNTER DATA PROVENANCE & REALITY DIRECTIVES

This rule enforces the `mockhunter` skill (`.agents/skills/mockhunter/SKILL.md`) across all pages, endpoints, and UI views in this repository.

## Core Mandate:
Every rendered value and metric must be traceable to its true origin:
1. **REAL**: Sourced from actual database queries (PostgreSQL), authentic third-party APIs (Stripe, GitHub, AWS, etc.), or verified runtime execution.
2. **MOCK**: Fabricated via `faker`, `Math.random`, seeded arrays, or in-memory stubs masquerading as real data. **PROHIBITED IN PRODUCTION.**
3. **HARDCODED**: Static numbers, strings, or fake metrics placed directly in JSX/HTML. **PROHIBITED IN PRODUCTION.**
4. **LLM**: Hallucinated or generated by an LLM without deterministic backing. Must be clearly labeled if used for assistance, and NEVER used as authoritative security decisions.
5. **BROKEN**: Endpoints returning 4xx/5xx or unhandled promise rejections hidden by empty states. **MUST BE LOGGED AND EXPOSED.**

## Verification Workflow:
- Audit pages using Playwright / Browser Subagent against live endpoints.
- Trace every visible metric through DOM -> Network -> API -> Database.
- Produce structured Markdown reports documenting Provenance, Severity (P0/P1), and Remediation Action.
