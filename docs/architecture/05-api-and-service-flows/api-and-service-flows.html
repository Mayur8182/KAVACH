    autonumber
    actor User as Next.js Client
    participant GW as FastAPI Gateway
    participant Worker as TaskWorker
    participant Scanners as Semgrep / OPA
    participant DB as PostgreSQL DB

    Note over User,DB: Flow 1: Scan Trigger & Enqueue
    User->>GW: POST /api/v1/scans { repo_id }
    GW->>DB: INSERT github_security_jobs (status='QUEUED')
    GW->>Worker: Enqueue Task (job_id)
    GW-->>User: HTTP 202 Accepted { job_id }

    Note over Worker,DB: Flow 2: Deterministic Scan & Ingest
    Worker->>Scanners: Execute Semgrep & Gitleaks CLI
    Scanners-->>Worker: Raw Findings JSON
    Worker->>DB: UPSERT security_findings (deduplicate)
    Worker->>DB: UPDATE job (status='COMPLETED', count=N)

    Note over User,DB: Flow 3: AI Remediation & Rescan Gate
    User->>GW: POST /api/v1/remediation/fix { finding_id }
    GW->>Worker: LLM Synthesizes Unified Diff
    Worker->>Scanners: Rescan Patched Scratch Workspace
    Scanners-->>Worker: 0 Findings (Verification PASS)
    Worker->>DB: Save Verified Patch & Audit Event
    GW-->>User: Return Verified Diff for PR
